How should we position Sifu now?

The Swift app changes the product story. Which framing fits best?

Context: Sifu used to be "a Python CLI you pip install." Now it's a native macOS app (Swift) for capture + a Python CLI for analysis. The install story, hero messaging, and product framing all need to shift.

A

Native Mac App (Lead with Swift)

Hero: "Your workflow sensei. A native macOS app that watches you work and turns everything into documentation, coaching, and automation."

Install CTA: Download SifuBar.app → drag to Applications
CLI mentioned as: "Power user tools" secondary section
Vibe: Polished product. App icon. Menu bar screenshots. "Just works."

Pros

  • Feels like a real product, not a dev tool
  • Native app = trust for non-developers
  • Simple install story

Cons

  • Still requires Python CLI for analysis
  • No code signing / DMG yet
  • Hides the CLI power
B

Developer Tool (Lead with CLI, Swift is the engine)

Hero: "Record workflows. Classify every step. Automate what's automatable. Open-source CLI for macOS."

Install CTA: git clone + pip install + swift build
Swift mentioned as: "Native capture engine" in architecture section
Vibe: Hacker tool. Terminal screenshots. Power user audience.

Pros

  • Honest about what it is today
  • Appeals to the audience that actually uses it
  • CLI-first matches current distribution

Cons

  • Limits audience to developers
  • Multi-step install is friction
  • Undersells the native quality
C

Hybrid (App + CLI, equal billing)

Hero: "Work normally. Get SOPs, coaching, and optimized workflows automatically. Native macOS capture + CLI-powered analysis."

Install CTA: Two steps — "1. Install the app 2. Install the CLI"
Architecture shown as: First-class diagram (Swift captures → CLI analyzes)
Vibe: Professional tool with depth. Shows the full pipeline.

Pros

  • Accurate to the architecture
  • Shows sophistication without hiding complexity
  • Consulting story: "we configured this for you"

Cons

  • Two install steps = more friction
  • Might confuse "is this an app or a CLI?"
  • Harder to make a clean hero
